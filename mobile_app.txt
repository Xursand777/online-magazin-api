BOZOR MOBILE APP UCHUN TEXNIK TOPSHIRIQ (TZ)
Versiya: 1.0
Sana: 2026-05-01

1. LOYIHA MAQSADI

Bozor web saytiga mos, lekin mobile qurilmalar uchun alohida qulay, tez, zamonaviy va professional e-commerce ilova ishlab chiqish kerak. Ilova mavjud backend API bilan ishlashi, web saytdagi asosiy biznes logikani saqlashi va mobil foydalanuvchi uchun ergonomik interfeys berishi kerak.

Ilova quyidagi asosiy bo'limlardan iborat bo'ladi:
- Home
- Catalog
- Savat
- Profile

Qo'shimcha kiriladigan sahifalar:
- Search natijalari
- Product detail
- Section pages: Tavsiya etamiz, Chegirmadagi mahsulotlar, Yangi mahsulotlar, Ommabop mahsulotlar
- Checkout
- Order detail
- Auth: telefon raqam, 6 xonali kod/parol, ro'yxatdan o'tish
- Settings: theme, account, logout

Ilova web sayt bilan bir xil backenddan ma'lumot oladi. Admin panel mobile ilovaga kiritilmaydi, lekin admin web panel orqali qo'shilgan mahsulotlar, bannerlar, kategoriyalar, variantlar va buyurtma statuslari mobile ilovada to'g'ri ko'rinishi shart.

2. TEXNOLOGIYA TALABLARI

Tavsiya etilgan stack:
- React Native + Expo + TypeScript
- TanStack Query yoki shunga teng server-state manager
- Zustand yoki Redux Toolkit cart/auth/theme state uchun
- React Navigation
- Expo SecureStore tokenlar uchun
- AsyncStorage guest cart, theme, search history uchun
- Axios API client
- Reanimated/Moti animatsiyalar uchun

Sabab:
- Hozirgi frontend React/TypeScriptga yaqin.
- API client va state logicni webdagi uslubga yaqin yozish oson.
- iOS va Android uchun bitta codebase.

Ilova minimum qo'llab-quvvatlashi:
- iOS 14+
- Android 8+
- Responsive mobile layout: 360px dan 430px gacha telefon ekranlari, planshet uchun kengaytirilgan grid.

5. API VA BACKEND INTEGRATSIYA

Mobile app mavjud backend API bilan ishlaydi.

Kerakli APIlar:
- GET /api/main/
- GET /api/banners/
- GET /api/products/
- GET /api/products/{id}/
- GET /api/products/{id}/similar/
- GET /api/search/products/?q=&track=true
- GET /api/categories/
- GET /api/categories/{id}/products/
- GET /api/products/discounts/
- GET /api/products/new/
- GET /api/products/popular/
- POST /api/auth/login/
- POST /api/auth/verify-otp/
- POST /api/auth/login-password/
- POST /api/auth/register/
- POST /api/auth/refresh/
- GET /api/profile/
- PATCH /api/profile/
- GET /api/cart/
- POST /api/cart/items/
- PATCH /api/cart/items/{id}/
- DELETE /api/cart/items/{id}/
- POST /api/cart/sync-local/
- POST /api/orders/from-cart/
- POST /api/orders/quick/
- GET /api/orders/
- GET /api/orders/{id}/
- POST /api/orders/{id}/cancel/

Token:
- access token SecureStoreda saqlanadi.
- refresh token SecureStoreda saqlanadi.
- 401 bo'lsa refresh ishlaydi.
- Refresh ham xato bersa user logout qilinadi va login screen ochiladi.

Offline/minimal network behavior:
- Home, catalog va product detailda cached data ko'rsatiladi.
- Internet yo'q bo'lsa aniq empty/error state chiqadi.
- Cart guest mode localda ishlashi mumkin.
- Checkout, order create, login faqat internet bilan ishlaydi.

6. AUTH FLOW

Kirish:
1. Telefon raqam kiritish.
2. Telefon tasdiqlangandan keyin 6 xonali kod/parol maydoni chiqadi.
3. Kod/parol kiritiladi.
4. Muvaffaqiyatli login bo'lsa:
   - tokenlar saqlanadi
   - local cart backendga sync qilinadi
   - user redirect qilingan sahifaga qaytariladi

Telefon input:
- +998 prefix alohida ko'rinadi.
- Faqat 9 raqam kiritiladi.
- Mask: 90 123 45 67 yoki 91 1234567 uslubida bo'lishi mumkin.

Kod/parol input:
- 6 xonali alohida cell input.
- Auto focus keyingi cellga o'tadi.
- Paste qilsa 6 xonani avtomatik tarqatadi.
- Xato kodda input shake animatsiya va error text.

Register:
- Telefon raqam
- Parol
- Parol tasdiqlash
- Terms accepted checkbox
- Muvaffaqiyatli bo'lsa verify flow.

Guest behavior:
- Login qilmagan user mahsulotni savatga qo'sha oladi.
- Checkout bosilganda login talab qilinadi.
- Login bo'lgandan keyin local cart backend cartga sync bo'ladi va local cart tozalanadi.
